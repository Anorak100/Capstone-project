# Fhast Pay Frontend: TS Academy group 13 project

The frontend application for the Fhast Pay banking system.

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- CSS Modules

## Features

- User registration and login
- Customer dashboard
- Account balance
- Recipient lookup
- Money transfers
- Transaction history

## Setup

Frontend runs on:

```text
http://localhost:5173
```

The frontend connects to the Fhast Pay backend API for authentication and banking operations.

## Status

Frontend API integration completed and production build tested successfully.
